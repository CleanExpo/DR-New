## Content Quality Checklist (Every Page)

### SEO Technical
- [ ] H1 with primary keyword
- [ ] URL slug includes location/keyword
- [ ] Meta title (50-60 chars, keyword + location)
- [ ] Meta description (150-160 chars, CTA + phone)
- [ ] 5-10 internal links minimum
- [ ] FAQ schema markup
- [ ] LocalBusiness/Service schema
- [ ] Breadcrumb schema
- [ ] Image alt text with keywords
- [ ] Mobile-responsive
- [ ] Page load < 3 seconds

### Content Quality
- [ ] 2000+ words (location pages)
- [ ] 2500+ words (authority pages)
- [ ] Unique content (no duplicates)
- [ ] Location-specific (not generic)
- [ ] No fake statistics or testimonials
- [ ] Client-verified facts only
- [ ] Emergency CTA above fold
- [ ] Phone number prominent
- [ ] Professional, trustworthy tone
