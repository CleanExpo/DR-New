## EMERGENCY CONTACTS

### If Something Goes Wrong:

**Misquote/Factual Error:**
- [ ] Use "Response 5: Decline/Redirect" template from PR Strategy
- [ ] Stay professional and helpful (journalist relationship is long-term)
- [ ] Offer correction with evidence
- [ ] Don't burn bridges

**Negative Coverage:**
- [ ] Assess if response needed or if silence is better
- [ ] Prepare factual, non-defensive response if required
- [ ] Consider offering follow-up interview for balance
- [ ] Learn and adjust future pitches

**Journalist Complains About Pitching:**
- [ ] Apologize immediately
- [ ] Ask for feedback on what to improve
- [ ] Remove from pitch list if requested
- [ ] Note preferences in database for future
