## 2. Brand Descriptions

### Disaster Recovery

| Attribute | Detail |
|---|---|
| **Type** | Consumer-facing marketplace platform |
| **Operating Entity** | Disaster Recovery Pty Ltd (ABN 85 151 794 142) |
| **Website** | https://disasterrecovery.com.au |
| **Target audience** | Property owners (residential and commercial) affected by natural disasters or property damage |
| **Function** | Connects property owners with qualified, verified restoration contractors |
| **Revenue** | Commission on matched jobs, featured listings, lead generation fees |

**What it does:**
- Property owners submit requests for restoration work (flood, fire, storm, mould, general restoration)
- The platform matches requests with verified contractors based on location, specialisation, and availability
- Contractors submit quotes through the platform
- Property owners select a contractor and engage them
- The platform facilitates the connection and takes a commission

**What it does NOT do:**
- Does not employ contractors
- Does not guarantee contractor work quality (contractors are independent operators)
- Does not process payment between property owner and contractor (in the standard model)

## 3. How the Brands Interrelate

### Operational Flow

```
PROPERTY DAMAGE OCCURS
        |
        v
+------------------+     +------------------+     +------------------+     +------------------+
| RESTORE ASSIST   |---->| DISASTER         |---->| NRPG             |---->| CARSI            |
| (DR Pty Ltd)     |     | RECOVERY         |     | (DR Pty Ltd)     |     | (McGurk Trust)   |
|                  |     | (DR Pty Ltd)     |     |                  |     |                  |
| Helps homeowner  |     | Matches with     |     | Provides         |     | Delivers         |
| with insurance   |     | qualified        |     | certified        |     | training &       |
| claim            |     | contractor       |     | contractors      |     | education        |
+------------------+     +------------------+     +------------------+     +------------------+
```

1. **Property damage occurs** (storm, flood, fire, mould, etc.)
2. **Restore Assist** helps the property owner navigate their insurance claim
3. **Disaster Recovery** matches the property owner with a qualified contractor
4. **NRPG** has previously certified and verified the contractor
5. The contractor performs the restoration work
6. The platform earns commission; the contractor maintains their NRPG membership

### Cross-Brand Referrals
- Restore Assist refers clients to Disaster Recovery for contractor matching
- Disaster Recovery features NRPG-certified contractors as verified professionals
- NRPG members gain access to job leads through the Disaster Recovery marketplace
- The ecosystem is designed so each brand reinforces the others

## 5. Trademark Registration Approach

### Strategy
Register each brand name as a trademark in both Australia and New Zealand to protect the intellectual property.

### Australia - IP Australia

**Portal:** https://www.ipaustralia.gov.au/trade-marks/applying-for-a-trade-mark

| Mark | Type | Suggested Classes |
|---|---|---|
| **Disaster Recovery** | Word mark + logo | Class 35 (business management, marketplace services), Class 37 (building restoration), Class 42 (SaaS, technology platform) |
| **NRPG** / **National Restoration Partners Guild** | Word mark + logo | Class 35 (professional association, certification services), Class 41 (training and education) |
| **Restore Assist** | Word mark + logo | Class 35 (business assistance), Class 36 (insurance services/claims assistance) |

**Costs (AU):**
| Item | Cost (approx. AUD) |
|---|---|
| Application fee per class (TM Headstart) | ~$330 |
| Application fee per class (standard) | ~$250 |
| Registration fee per class (if accepted) | Included in application |
| Multi-class discount | May apply |
| **Estimated total (3 marks, 2-3 classes each)** | **$1,500 - $3,000** |

### Trademark Registration Steps

#### Pre-Filing
- [ ] Conduct trademark searches on IP Australia (ATMOSS) for each mark
- [ ] Conduct trademark searches on IPONZ for each mark
- [ ] Check for conflicting marks or prior registrations
- [ ] Confirm the classes of goods/services for each mark
- [ ] Consider engaging a trademark attorney for the filing process

#### Filing (Australia)
- [ ] File trademark application for "Disaster Recovery" via IP Australia
- [ ] File trademark application for "NRPG" / "National Restoration Partners Guild" via IP Australia
- [ ] File trademark application for "Restore Assist" via IP Australia
- [ ] Monitor for examination reports and respond within deadlines
- [ ] Monitor for oppositions during the opposition period

#### Filing (New Zealand)
- [ ] File trademark application for "Disaster Recovery" via IPONZ
- [ ] File trademark application for "NRPG" / "National Restoration Partners Guild" via IPONZ
- [ ] File trademark application for "Restore Assist" via IPONZ
- [ ] Monitor for examination reports and respond within deadlines
- [ ] Monitor for oppositions during the opposition period

### Timeline
| Stage | Timeframe |
|---|---|
| Search and preparation | 1-2 weeks |
| Filing | 1 day |
| Examination (AU) | 4-6 months |
| Examination (NZ) | 3-6 months |
| Opposition period | 2-3 months after acceptance |
| Registration (if no opposition) | 8-12 months total |

### Important Notes
- Trademark rights are territorial; Australian registration does not protect in NZ and vice versa
- Consider filing in NZ promptly if the NZ expansion is imminent
- "Disaster Recovery" may face examination issues as it could be considered descriptive; a trademark attorney can advise on strategies to overcome this
- The NRPG name and logo are likely more distinctive and easier to register
- Maintain records of first use of each mark in commerce (supports the application)
