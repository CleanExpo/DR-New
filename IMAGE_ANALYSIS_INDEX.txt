USEFUL COMMANDS FOR IMAGE MANAGEMENT
================================================================================

Find all images by size (largest first):
  find . -type f \( -iname "*.jpg" -o -iname "*.png" -o -iname "*.webp" \) \
    -exec ls -lh {} \; | sort -k5 -hr | head -20

Find duplicate filenames:
  find . -type f -iname "*" -print | sed 's|^\./||' | \
    sort | uniq -d | head -50

Check total image size by folder:
  du -sh public/images public/logos image-library mobile-app/assets

List all PNG files larger than 500KB:
  find . -type f -iname "*.png" -size +500k

Count images by format:
  echo "PNG:" && find . -iname "*.png" | wc -l
  echo "WEBP:" && find . -iname "*.webp" | wc -l
  echo "JPG:" && find . -iname "*.jpg" | wc -l

Find images missing WEBP equivalent:
  for file in $(find public/images -iname "*.png"); do
    base="${file%.png}"
    [ ! -f "${base}.webp" ] && echo "$file"
  done
