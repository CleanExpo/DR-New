### 3. **Technical SEO Essentials**

#### Meta Tags (REQUIRED on every page):
```html
<title>Unique Title - Brand Name</title>
<meta name="description" content="Unique description 150-160 chars">
<meta property="og:title" content="Title for social">
<meta property="og:description" content="Social description">
<meta property="og:image" content="https://yoursite/image.jpg">
<meta name="robots" content="index, follow">
<link rel="canonical" href="https://www.disasterrecovery.com.au/page">
```

#### Header Tags Structure:
- ONE H1 per page (primary keyword)
- Multiple H2s (section headings)
- H3s for subsections
- Logical hierarchy
