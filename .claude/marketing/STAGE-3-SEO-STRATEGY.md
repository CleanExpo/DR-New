### Body Content Optimization

#### Keyword Density
- Primary keyword: 1-2% of content (not more)
- Secondary keywords: Naturally included
- Long-tail variants: Natural inclusion
- Goal: Content feels natural, not keyword-stuffed

#### Content Structure
```
1. Introduction (150-200 words)
   - Include primary keyword
   - Establish relevance
   - Value proposition

2. Main Sections (3-4 sections, 200-300 words each)
   - H2 subheadings
   - Include keyword variations
   - Provide genuine value
   - Internal links to guides

3. Testimonials Section (100-150 words)
   - Social proof
   - Real customer quotes
   - Results/outcomes

4. FAQ Section (6-8 questions)
   - Answer commonly searched questions
   - Include question keywords
   - 50-100 words per answer

5. Call-to-Action (50-75 words)
   - Clear value proposition
   - Button copy includes benefit

Total content: 1,200-1,500 words per page
```

## Common SEO Mistakes to Avoid

```
❌ DON'T: Keyword stuff (looks spammy, violates guidelines)
❌ DON'T: Create pages just for SEO (need genuine user value)
❌ DON'T: Buy backlinks (violates Google guidelines, risky)
❌ DON'T: Duplicate content across insurer pages (each unique)
❌ DON'T: Ignore mobile experience (60%+ traffic is mobile)
❌ DON'T: Neglect internal linking (helps crawl, distributes authority)
❌ DON'T: Use auto-generated content (Google can detect it)
❌ DON'T: Hide text or links (black hat technique, penalized)
❌ DON'T: Ignore page load speed (Core Web Vitals important)
❌ DON'T: Forget about E-E-A-T (Expertise, Experience, Authority, Trustworthiness)
```
