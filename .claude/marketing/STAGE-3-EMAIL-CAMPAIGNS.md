## Email Campaign Overview

### Strategy
Send 3-email sequences to prospects who have:
1. Visited insurer landing page
2. Downloaded insurance guide
3. Engaged with website content about insurance/restoration

### Campaign Structure
```
Email 1: Educational (Day 1-3 after trigger)
"Working with [Insurer]? Here's What You Need to Know"
Purpose: Build trust, educate about process

Email 2: Documentation (Day 5-7 after trigger)
"Documentation Checklist for [Insurer] Claims"
Purpose: Provide value, position as helpful resource

Email 3: Call-to-Action (Day 10-12 after trigger)
"Your Rights When Working with [Insurer]"
Purpose: Convert to contractor match
```

### Triggers
```
Segment 1: Landing Page Visitors
- User visited /insurance/[insurer]-* page
- No CTA click
- Send Email 1 after 2 days

Segment 2: Guide Downloaders
- User downloaded insurance guide
- Segmented by guide type
- Send Email 1 after 1 day

Segment 3: Re-engagement
- User visited website 3+ times but no conversion
- Send Email 1 after delay period
```

## Email Design Notes

### Layout
```
Width: 600px (optimal for desktop and mobile)
Mobile: Stack single column, 100% width
Margins: 20px padding on sides (mobile)
```

### Typography
```
Headers: Bold, 24-28px
Subheaders: Bold, 18-20px
Body: Regular, 16px (mobile), 14-16px (desktop)
Line height: 1.5 (readable)
Color: Dark gray (#333333), not pure black (#000000)
```

### Colors
```
Primary CTA: Insurer brand color
Secondary CTA: NRPG brand color (#4F46E5)
Links: Underlined, teal (#0891B2)
Backgrounds: White or very light gray
```

### Images
```
Logo: 200x80px (PNG, white background)
Hero image: 600x300px (relevant to insurer/topic)
Icons: 40x40px (if using bullet points)
```
