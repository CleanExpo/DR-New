## 📦 Database Ready Format

### File Location
```
data/content/month-1-articles-complete.json
```

### Insertion Process

**Using Prisma Client**:
```typescript
import { prisma } from '@/lib/db/prisma';
import articles from '@/data/content/month-1-articles-complete.json';

// Insert articles in DRAFT status
for (const article of articles.articles) {
  await prisma.blogPost.create({
    data: {
      title: article.title,
      slug: article.slug,
      content: article.content,
      metaTitle: article.metaTitle,
      metaDescription: article.metaDescription,
      keywords: article.keywords.join(','),
      status: 'DRAFT',
      authorId: 1, // Phil McGurk or main author
      viewCount: 0
    }
  });
}
```

### Required Database Fields
- `title`: Article heading
- `slug`: URL-friendly slug (auto-generated from title)
- `content`: Full article HTML/markdown content
- `metaTitle`: SEO title tag (60 characters)
- `metaDescription`: Meta description (160 characters)
- `keywords`: Comma-separated keyword list
- `status`: DRAFT | SCHEDULED | PUBLISHED

### Optional Fields
- `htmlContent`: Pre-rendered HTML version
- `publishedAt`: Publication timestamp
- `scheduledFor`: Scheduled publication date
- `authorId`: Author ID (for attribution)
- `viewCount`: View counter (starts at 0)
