## 📊 Landing Pages to Create (4 Primary Pages)

**URL:** `/launch` or `/waitlist`
**Purpose:** Capture early adopter emails for launch announcement
**Target Audience:** Property owners + contractors
**Campaign Sources:** Social media, direct traffic, email campaigns

**Key Elements:**
1. **Hero Section**
   - Headline: "Australia's First IICRC-Verified Disaster Recovery Network - Launching Soon"
   - Subheadline: "Join 500+ property owners and contractors waiting for trusted, transparent disaster restoration"
   - Hero Image: Professional restoration team at work
   - CTA: "Join the Waitlist" (email capture)

2. **Value Propositions** (3 columns)
   - ✓ Verified IICRC-Certified Contractors Only
   - ✓ 24/7 Emergency Response Nationwide
   - ✓ Transparent Pricing, No Hidden Fees

3. **How It Works** (3 steps)
   - Step 1: Submit Your Claim (2 minutes)
   - Step 2: Get Matched with Verified Contractors
   - Step 3: Track Your Restoration Progress

4. **Social Proof**
   - "Join 500+ people on the waitlist"
   - Logos: IICRC certification, Australian business badges
   - Testimonials: Early beta tester quotes (if available)

5. **Email Capture Form**
   - Fields: Email, Full Name, User Type (Property Owner / Contractor)
   - Checkbox: "I agree to receive launch updates and disaster recovery tips"
   - CTA Button: "Reserve Your Spot - Join Waitlist"
   - Privacy note: "We respect your privacy. Unsubscribe anytime."

6. **FAQ Section** (Accordion)
   - When will the platform launch?
   - Is there a cost to join the waitlist?
   - What happens after I join?
   - Who can use the platform?

7. **Footer**
   - Social proof counter
   - Social media links
   - Contact email

**Success Metrics:**
- Conversion rate: 20-40% (email capture from visitors)
- Bounce rate: <60%
- Time on page: >1 minute

### Database Schema Updates

**New Table: WaitlistSubmission**
```prisma
model WaitlistSubmission {
  id            String   @id @default(cuid())
  email         String   @unique
  fullName      String
  userType      String   // "PROPERTY_OWNER" | "CONTRACTOR"
  source        String?  // Campaign source (google-ads, facebook, organic, etc.)
  utmSource     String?
  utmMedium     String?
  utmCampaign   String?
  consentEmail  Boolean  @default(false)
  createdAt     DateTime @default(now())
  updatedAt     DateTime @updatedAt

  @@index([email])
  @@index([createdAt])
  @@index([source])
}
```

**New Table: ContractorApplication**
```prisma
model ContractorApplication {
  id                String   @id @default(cuid())
  businessName      String
  contactName       String
  email             String
  phone             String
  abn               String
  certifications    String[] // IICRC cert types
  serviceAreas      String[] // Postcodes or states
  yearsInBusiness   Int
  status            String   @default("PENDING") // PENDING | APPROVED | REJECTED
  notes             String?
  source            String?  // Campaign source
  utmSource         String?
  utmMedium         String?
  utmCampaign       String?
  createdAt         DateTime @default(now())
  updatedAt         DateTime @updatedAt

  @@index([email])
  @@index([status])
  @@index([createdAt])
}
```


### Component Patterns

**Hero Section:**
- Full-width background image with overlay
- Centered text (responsive: left-aligned on mobile)
- Large headline (text-4xl md:text-6xl)
- Prominent CTA button (min 200px width, 56px height)

**Forms:**
- White background, rounded corners (rounded-lg)
- Clear labels above inputs
- Validation errors below fields (red text)
- Submit button always visible (sticky on mobile)
- Success state with checkmark icon

**Trust Badges:**
- Icon + text combination
- Rounded background (bg-gray-50)
- Hover effect (scale-105 transition)

**CTAs:**
- Primary: Orange background, white text, shadow-lg
- Secondary: White background, orange border, orange text
- Size: px-8 py-4 text-lg (large), px-6 py-3 text-base (medium)
- Hover: Slight lift effect (hover:shadow-xl hover:-translate-y-0.5)
