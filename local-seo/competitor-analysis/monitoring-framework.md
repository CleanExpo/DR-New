## 💪 COMPETITIVE RESPONSE STRATEGIES

### If Competitor Gains Review Momentum

**Immediate Actions (Within 48 Hours):**
1. **Intensify Review Requests**
   - Send additional SMS follow-ups
   - Add email sequence touchpoint
   - Call top customers personally

2. **Boost Social Proof Posts**
   ```
   Post Example:
   "Thank you for 150+ five-star reviews Brisbane!
   Real families, real results. See why neighbours
   choose local expertise over franchises."
   ```

3. **Highlight Differentiators**
   - Family-owned vs franchise
   - 25+ years vs newcomers
   - Local base vs remote response

**Week-Long Campaign:**
- Day 1-2: Email blast to past customers
- Day 3-4: SMS review requests
- Day 5-7: Phone follow-ups to recent jobs

### If Competitor Adds New Service

**Evaluation Protocol:**
```
NEW SERVICE ASSESSMENT

Service: [What they added]
Date Noticed: [Date]

VIABILITY ANALYSIS:
□ Within our expertise? Y/N
□ Insurance covered? Y/N
□ Equipment required? $____
□ Training needed? Hours: ___
□ Market demand? High/Med/Low
□ Profit margin? __%

DECISION:
□ Add immediately (if already capable)
□ Plan addition (develop capability)
□ Ignore (outside scope)
□ Counter with strength (emphasize what we do better)

RESPONSE TIMELINE:
- Day 1: Team discussion
- Day 3: Decision made
- Day 5: If adding, update GBP
- Day 7: Announce via post
```

### If Competitor Dominates Keywords

**Keyword Recapture Strategy:**

1. **Audit Their Success**
   - Which keywords ranking for?
   - What content drives ranking?
   - Category selections?
   - Description optimization?

2. **Content Optimization Blitz**
   ```
   7-Day Keyword Domination Plan:

   Day 1: Update business description with target keywords
   Day 2: Add keyword-rich Q&As (5 questions)
   Day 3: Upload photos with keyword captions
   Day 4: Publish keyword-focused post
   Day 5: Add service with keyword in title
   Day 6: Respond to reviews using keywords
   Day 7: Update website landing pages
   ```

3. **Amplification Tactics**
   - Create location + keyword posts
   - Add keywords to photo descriptions
   - Include in review responses
   - Update service descriptions

## 🚨 COMPETITOR CRISIS RESPONSE

### If Competitor Has Negative Event

**Ethical Response Protocol:**
1. Never directly reference their issues
2. Focus on our positives, not their negatives
3. Increase visibility naturally
4. Let reputation speak for itself

**Appropriate Messaging:**
```
"Brisbane families have trusted our certified team
for 25+ years. See why experience matters when
disaster strikes. 150+ five-star reviews."
```

**NOT Appropriate:**
```
"Unlike others facing complaints, we..."
"While competitors struggle with..."
```

### If We're Attacked

**Response Framework:**
1. Document everything (screenshots, dates)
2. Report to Google if false information
3. Focus on positive messaging
4. Rally customer support organically
5. Consider legal if defamatory
