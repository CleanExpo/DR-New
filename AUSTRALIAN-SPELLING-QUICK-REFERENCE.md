## Most Common Changes Made

### Top 10 Most Frequent Conversions:

1. **center → centre** (Most common - thousands of instances)
   - "contact centre" not "contact center"
   - "city centre" not "city center"
   - CSS: `items-centre`, `justify-centre` (Tailwind classes)

2. **specialized → specialised** (103 instances)
   - "specialised flood restoration"
   - "specialised storm damage expertise"
   - "Master Restorer with specialised training"

3. **optimize → optimise / optimization → optimisation**
   - "optimised drying techniques"
   - "ventilation optimisation"
   - Note: `/images/optimized/` paths were NOT changed

4. **minimize → minimise**
   - "minimise business disruption"
   - "minimise secondary damage"

5. **prioritize → prioritise**
   - "we prioritise emergency response"
   - "prioritise flood-prone areas"

6. **recognize → recognise**
   - "recognised certifications"
   - "industry-recognised standards"

7. **analyze → analyse**
   - "analyse building structure"
   - "moisture analysis"

8. **behavior → behaviour**
   - "customer behaviour"
   - Note: CSS `scroll-behavior` was NOT changed

9. **dialog → dialogue**
   - "open dialogue with clients"
   - Note: Technical modals/UI kept as "dialog"

10. **maximize → maximise**
    - "maximise insurance coverage"
    - "maximise drying efficiency"

## What Was NOT Changed

### Technical Terms Preserved:
1. **File paths**: `/images/optimized/` (system paths)
2. **CSS properties**: `color:`, `background-color` (standard CSS)
3. **Package names**: npm package names (international standards)
4. **Library names**: Third-party library references
5. **Technical IDs**: Database IDs, API endpoints
6. **Code variables**: JavaScript variable names in camelCase

### Example - What Stayed American:
```javascript
// Code variable names - NOT changed
const optimizedImages = [...];  // Variable name stays American
color: '#0052CC',                // CSS property stays American
/images/optimized/flood.jpg      // File path stays American

// User-facing text - CHANGED
"Optimised image delivery"       // Changed from "Optimized"
"Colour scheme matching"         // Changed from "Color"
"Centre of operations"           // Changed from "Center"
```
