## Technical Notes

### React/Next.js Considerations
- All sections use Tailwind CSS classes (r6-* utility classes)
- Image components use Next.js Image for optimization
- Links use Next.js Link component for client-side routing
- Phone numbers use `tel:` protocol for mobile click-to-call
- Schema markup as JSON-LD in script tags

### Performance Optimization
- Lazy load images below fold
- Defer non-critical CSS
- Minimize layout shift (CLS)
- Optimize largest contentful paint (LCP)
- Ensure interactive elements respond quickly (FID/INP)

### Accessibility
- Semantic HTML structure (h1, h2, h3 hierarchy)
- Alt text on all images
- ARIA labels on interactive elements
- Keyboard navigation support
- Color contrast ratios meet WCAG AA

### Mobile Optimization
- Responsive grid layouts (md:grid-cols-2, lg:grid-cols-3)
- Touch-friendly button sizes (min 44x44px)
- Readable font sizes (16px minimum)
- Click-to-call phone links
- Fast mobile page speed (<3s)
