## TROUBLESHOOTING GUIDE

### Issue: Schema Not Appearing

**Symptoms**: Google Rich Results Test shows no schema

**Solutions**:
1. Check page source - is `<script type="application/ld+json">` present?
2. View browser console - any JavaScript errors?
3. Is schema server-side rendered? (not client-only)
4. Check Next.js build completed successfully

---

### Issue: Schema Errors in Validator

**Symptoms**: Red errors in Schema.org validator

**Common Causes**:
1. Missing required fields
2. Invalid @type value
3. Broken @id reference
4. Malformed JSON syntax

**Fix**:
1. Copy error message
2. Find field in schema component
3. Check against Schema.org documentation
4. Update and retest

---

### Issue: Knowledge Panel Not Showing

**Symptoms**: No panel after 8 weeks

**Causes**:
1. Google hasn't processed yet (be patient)
2. Schema on homepage missing
3. sameAs links invalid
4. Google Business Profile not connected

**Solutions**:
1. Verify schema on homepage
2. Check all social links work
3. Request panel via Google Business
4. Submit feedback to Google
5. Wait another 4 weeks
